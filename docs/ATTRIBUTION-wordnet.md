# Open English WordNet attribution and redistribution boundary

The optional adapter in `scripts/wordnet_store.py` reads an external Open
English WordNet archive. No WordNet data or derived extract is distributed in
this repository.

Open English WordNet is maintained by the Global WordNet Association project
and released under Creative Commons Attribution 4.0. Its canonical citation is
John P. McCrae, Alexandre Rademaker, Francis Bond, Ewa Rudnicka, and Christiane
Fellbaum, “English WordNet 2019 – An Open-Source WordNet for English,” GWC 2019.

- Project and license: https://github.com/globalwordnet/english-wordnet
- CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

The resource incorporates material descended from Princeton WordNet. Princeton
permits use, copying, modification, and distribution subject to retaining its
copyright notice, license terms, and warranty disclaimer on every copy.

- Princeton terms: https://wordnet.princeton.edu/license-and-commercial-use

If a WordNet artifact or reduced derivative is ever distributed with this
project, its release gate must include the upstream OEWN license, attribution,
canonical citation, and the complete applicable Princeton notice/disclaimer
beside that artifact. A URL in this file alone is not a substitute for those
notices. The current adapter-only distribution triggers no data redistribution.
