## The headline: the system can now be *driven*, and the cheap baseline still wins

v0.7 turned single demonstrations into families with capability-blind baselines.
v0.8 does two things with that discipline: it **opens** the one capability v0.7
deferred — unrestricted prose authoring through the interactive harness, the
first surface a real user (or a less constrained author) can drive — and it
**closes** four lanes v0.7 shipped open. In every closed lane the honest result
held: the cheap baseline won, or the interface change did nothing, and we report
it.

- **The golden-chicken conversation can now be *authored in open prose*** that
  varies its surface wording while a sound closure gate proves no accepted fact
  moved — and it survives a serialize/restart and degrades to ASK, never a guess.
- **A trained corpus-analogy model was run against the real ceiling** — the
  strict ≈0.10–0.14 one v0.7 disclosed, not the inflated 0.400 — and it beats no
  blind baseline, sitting *at* the strict ceiling. The cheap nearest-template
  replay still wins the whole lane.
- **PROVEN-WRITE now accepts** a candidate end-to-end (seed written, corpus
  regenerated by trusted code, receipt reproducing the transition) and refuses
  another, byte-identically — through an audit that survived an adversary trying
  every escape.
- **The depth OOD blind spot is removed and the interface was manipulated**:
  enlarging the copy budget does not move OOD, and the retained cliff turns out
  to be an *early*-token failure, not the deep-tail truncation we predicted.

Under all of it, the same rule the project has always kept: no learned number is
sold as more than it is, and a negative result is a first-class result.

**Demonstrate:**

```console
python scripts/prose.py
python experiments/train_corpus_analogy.py
python experiments/depth_interface.py
python scripts/write_stage.py --apply <staged-candidate>
python scripts/harness.py
```

## Roadmap triage

### Shipped

- **Open-language requests through the interactive harness** (item 1). A
  microkernel session (`scripts/harness.py`) boots a capability matrix, runs the
  propose→verify→trace controller, and surfaces a pause as `StopReason.WAITING`
  through a subsystem-agnostic need channel; a need dispatcher (`scripts/dispatcher.py`)
  routes over registered subsystem paths with a hop budget and session-level loop
  detection (P-IH1/2/4/5/7 adjudicated). On top of it, `scripts/prose.py` authors
  the golden-chicken conversation in **open prose**: a constrained surface pointer
  varies wording (distinct-surface ratio 0.980 vs a rich template's 0.060) while a
  **closure/coverage/ordering gate** proves no accepted fact moved — it tiles the
  prose into approved fact-segments, requires kind-coverage equality, and enforces
  beat order and plant-before-discharge. Survives serialize/restart; degrades to
  ASK on an unrenderable fact.
- **PROVEN-WRITE earns an acceptance path** (item 4). `scripts/write_stage.py`
  now applies a cleared new-seed/new-corpus candidate by writing the audited seed
  and regenerating `data/<corpus>/nodes.json` through one trusted generator —
  atomically (temp→fsync→replace), with track-before-write rollback, a
  receipt-or-nothing guarantee, and a whole-tree delta assertion that only the
  declared seed and corpus may change. A refused candidate leaves the tree
  byte-identical. Independent review ran every corpus-escape, code-execution,
  audit/apply-divergence and receipt attack; all failed.
- **The corpus-analogy split gets its honest ceiling and its model arm**
  (item 2). An untyped-**shape** holdout (cut on shape, not typed skeleton) has
  blind ceiling **0.1069** — the strict regime v0.7 disclosed, with zero leak;
  the existing family/discipline/vocabulary ceilings are byte-unchanged. The first
  trained model arm (1.49M params, 3 seeds) scores **0.104 ± 0.012** on that cut —
  it beats no blind ceiling on any holdout.
- **Depth moves to the interface** (item 5). The conditional-only OOD blind spot
  is removed (unconditional metric reported beside retained, with per-depth
  capacity-exclusion counts — the 550 hidden rows are all depth 4/5). Enlarging
  the copy interface budget does **not** move untruncated OOD (a matched-control
  negative), and the retained cliff localizes to *early* deciles, not the deep end.

### Shipped as corrections and negative results

- **The trained analogy model loses to the blind baseline on every holdout** —
  0.168/0.491/0.201/0.104 against 0.400/0.9318/0.3976/0.1069. The v0.7 pattern
  holds one rung deeper: on genuinely unseen shapes the model internalizes no more
  of the pointing mechanism than a cheap edit-distance replay. This lane measures
  pointing, not reasoning, and the model does not clear the pointing bar.
- **The copy budget is not the depth bottleneck.** The interface manipulation is
  a negative: the previously-excluded rows still score 0.0 even fully untruncated
  (their targets exceed any budget the model was trained on), so the failure is a
  training-exposure/interface-boundary property, not a truncation artifact.
- **The depth cliff is early, not deep (P-DI3 missed).** We predicted the retained
  first-error mass concentrates in the late deciles; 0.751 of it lands in deciles
  0–2. Registered wording kept, correction attached.
- **The prose moved-fact control was unsound on first delivery.** A presence
  check certified four fact-moving adversaries (added premise, wrong owner,
  negation, dropped beat) as faithful; independent review blocked it, and the
  closure gate that replaced it now catches all of them plus temporally-scrambled
  and plant-after-discharge renders.

### Carried to v0.9

The open lanes v0.8 did not reach — proof-search curve depth (item 3), the
groundedness gate (item 7), the physics/affect/oscillation and visual-arm rungs
(items 6/8), and the existing-multi-corpus WRITE patch — carry to
[ROADMAP-v0.9.md](ROADMAP-v0.9.md). But v0.9's **headline is a deliberate pivot**,
argued in [DESIGN-corpus-scale-and-programming.md](DESIGN-corpus-scale-and-programming.md):
the limiting factor is no longer method, it is the **scale and external relevance
of the knowledge graph**. With the open harness now able to drive the system,
the majority of effort turns to (a) **non-toy verified corpora by ingestion**
(miniF2F / Mathlib / arXiv-with-proofs / cleaned ProofWiki through the existing
`seed_*.py` + schema pattern — ingest, don't invent) and (b) **programming as a
first-class discipline** (AST → canonical form → structural address → pointer
residual → external verifier). The elegant closed-world rungs wait until the core
graph is non-toy.

## See the improvement (Before → Now → Demonstrate)

### The conversation can be authored, not just filled

**Before:** the golden-chicken conversation was maintained, revisable, and
durable, but its rendering was a fixed template — the surface could not vary, and
"does the prose stay faithful to the accepted facts?" was not a question the
system could answer. **Now:** a constrained surface pointer authors the same facts
in varying prose, and a closure gate reads that prose and proves it asserts
exactly the accepted fact set — nothing added, dropped, negated, misattributed, or
reordered. A rich exact-template arm is compared on the same metrics (premise
preservation, beat coverage, temporal consistency, lexical variety, each measured
separately). **Demonstrate:** `python scripts/prose.py`.

### A proof of ownership that actually writes

**Before:** PROVEN-WRITE staged a candidate through fourteen gates and accepted
nothing — `approval_granted` was always empty. **Now:** a cleared candidate is
applied: the audited seed is written and its corpus regenerated by the one trusted
generator, atomically, with a receipt that reproduces the transition; anything
that would touch a file other than the declared seed and corpus rolls back and
raises. **Demonstrate:** the accept/refuse pair is in
`tests/test_write_stage.py::AcceptedWriteApplicationTests`; the CLI path is
`python scripts/write_stage.py --apply <candidate>`.

### The analogy model meets the real ceiling

**Before:** v0.7 shipped the split and disclosed that typed families inflated the
headline ceiling from a true ≈0.10–0.14 to 0.400, but trained no model. **Now:**
an untyped-shape holdout makes the strict 0.1069 ceiling concrete with zero leak,
and the first trained model arm scores 0.104 ± 0.012 on it — it does not clear the
blind baseline. **Demonstrate:**

```console
python experiments/train_corpus_analogy.py
cat experiments/results/corpus_analogy_model_arm.json
```

### Depth stops hiding its hardest rows

**Before:** depth OOD was reported on 2,450 of 3,000 generated rows; the 550
capacity exclusions (all depth 4/5) never entered the denominator, and it was
unknown whether the copy budget was the bottleneck. **Now:** the unconditional
metric is reported beside the retained one with per-depth exclusion counts, and
enlarging the copy budget is shown not to move OOD — the cliff is an early-token,
training-exposure failure. **Demonstrate:** `python experiments/depth_interface.py`.

## Discoveries of the cycle

- A moved-fact control that only checks for the presence of the right words will
  certify a narrative that adds, negates, or misattributes facts; only a closure
  check — the prose tiles into approved fact-segments and nothing else — has teeth.
- Detection after arbitrary code runs is not containment, and neither is a
  `data/`-only digest: a durable write is safe only when it is atomic, rolls back
  to byte-identity, and asserts a whole-tree delta of exactly the declared files.
- On genuinely unseen structural shapes, a trained pointer matches a blind
  edit-distance replay and no more — the residual this lane can learn is not there.
- The depth wall is not a truncation artifact and not a deep-tail collapse; it is
  an early-token failure on targets no budget ever trained. The interface, not the
  budget, is the object of study — as the v0.6 ablation already implied.

The full evidence lives in [DISCOVERIES.md](DISCOVERIES.md) and
[experiments/ANALYSIS.md](../experiments/ANALYSIS.md).

## Honest limits (and the pivot they force)

- The trained analogy model clears no blind ceiling; the depth interface result is
  a negative; open-prose fluency is deliberately flat, not LLM-comparable.
- **The corpus is still 221 hand-authored nodes across 22 disciplines** — the same
  as v0.7. Every result in this release lives inside a closed world the author
  fully controls. The proof-search curve, the analogy splits, the durable
  conversations, and the visual oracle are real and carefully measured, but the
  moment the system faces an uncontrolled, larger, messier body of knowledge, most
  of the current numbers become unknown. This — not method — is now the limiting
  factor, and v0.9 makes closing it the headline.
- Nothing here stands against general LLM benchmarks; the rule stays in force —
  no external comparison until the input/output contract maps honestly onto the
  capability actually built. The open harness earns the first half of that contract.

## Assets and their stories

**v0.8 ships no new model-weight assets, and that is the more honest artifact
here.** Both lanes that trained models this cycle produced NEGATIVE results, and
both are fully recorded — per seed, with provenance — in committed result JSON
that a reader can inspect without a GPU:

- `experiments/results/corpus_analogy_model_arm.json` — the 1.49M-param pointer's
  0.104 ± 0.012 on the strict shape holdout (beats no blind ceiling), with the
  four frozen ceilings and per-seed counts;
- `experiments/results/depth_interface.json` — the item-5 negative (budget does
  not move OOD), with retained/unconditional metrics, per-depth exclusion counts,
  the interface treatment, and the cliff localization.

The training checkpoints from the release runs are **seed-reproducible-only**:
CUDA is nondeterministic, so a re-derived checkpoint reproduces the same negative
but not the exact committed per-seed numbers. Shipping a weight that would not
match the committed JSON would be less faithful than shipping the JSON and the
deterministic script that produced it, so the committed evidence *is* the asset.
Retrain from the committed scripts (`experiments/train_corpus_analogy.py`,
`experiments/depth_interface.py`) to regenerate a checkpoint; the numbers will
land in the reported bands.

No licensed `experiments/data_real/` or WordNet archive ships, as in every prior
release.

## Release validation record

Validated on Windows against `main` after all five gate merges:

- all 14 seeds regenerated their committed corpora byte-identically;
- schema/link validation passed for 221/221 nodes across 22 corpora;
- the matcher reported 30 shape, 31 typed, 30 family, 32 aliased, 5 mirror groups,
  zero ladder violations;
- specialization regenerated 655 cheapest-derivation edges (566 cross-discipline);
  decomposition covered 193/221 statements at mean groundedness 0.770;
- proof correspondence reported 15 CORRESPONDS / 1 UNTRANSLATABLE / 0 MISMATCH;
- the full unit suite (781 tests) passed.

Every capability slice this cycle passed independent adversarial review before
merge; two returned blocking or should-fix findings (the prose control's
unsoundness, the WRITE accept-path atomicity) that were closed with regressions
before merge, and the two GPU measurement lanes were re-verified by independent
recomputation.
