# The inbound turn had no population

The last chapter ended with a person about to speak.

A library had been measured almost nameless — twelve thousand statements,
four hundred and seventeen a person could type to, one hundred and twenty-five
of those among the ones the engine can even consume in one step. That finding
was supposed to *clear* a path. The next step would not need names. A person
would supply a hypothesis the library does not contain; the system would
hand back a machine-checked implication, named, undischarged, and not
believed. A companion measurement would go first, asking whether a sentence
the system already speaks determines the statement it came from.

This is the release where that inbound turn was attempted. It did not start.

A stranger can carry the cycle in one sentence: **the questions we already
had were not about the part of the library that can speak, the native voice
is not an instrument we can echo, and the recorded answers we can replay did
not change.**

## What the last chapter left owing

[The library that had no names](the-library-that-had-no-names.md) closed on
a design written before that post, so the next question could not be chosen
after seeing the census. The design said: run on the roughly two thousand
three hundred statements the system can already speak in verified English —
the remainder that *does* have something to say its own name with. Echo the
voice first. Then let a person in.

The debt was specific. Either those two thousand three hundred are a
population a sealed question set can point at, or we learn that “the part
that can speak” and “the questions a maintainer wrote about this corpus”
are different objects.

They are different objects.

## The recast

Thirty plain-English questions had been sealed a cycle earlier, before a
proposer existed, with a warning in their own header: questions a maintainer
wrote about this corpus are not questions a stranger asks. This cycle took
that warning at its word and asked a narrower, checkable thing: do those
questions even name statements in the speakable remainder?

The rule was committed first, before any recast. It did not ask a search
index. It took only statement identifiers the sealed `why` fields already
wrote down, and asked whether each was a member of the same covered set the
voice already measures. Nine of the thirty were authored to exhaust — weather,
the Iliad, a stock tip — and they stayed outside. Of the remaining twenty-one,
**zero** named a unique covered identifier.

The identifiers they *did* name are real library objects: a complete-graph
edge count, an iterative factorial, a double-angle cosine. They live in the
hand-curated rooms of the library. The speakable remainder is ninety-nine
point eight seven percent bulk-ingested workbook problems. Register rules
block some of those curated names from the voice; others were never accepted
by the oracle that licenses speaking at all.

So the inbound slice had no restricted population. The design had already
said what to do if that population fell below fifteen: report the recast
yield, do not invent a forty-percent floor over an empty remainder. The
yield is the result. There is no file of fifty implications, because there
were no sessions to record.

A second arm was supposed to draw twenty real maintainer corrections from a
probe that an earlier cycle had parked *with* its log so the log could not
be read after the fact. The path was never written. The draw predicted that
absence, refused to author twenty objections in the same breath as the
measurement, and published an empty pool. That is not “underpowered.” There
is no sample.

## The voice that is two voices

The companion measurement went first, as promised, and stopped before its
pilot. “The voice” is two disjoint universes: eight thousand five hundred
eighty-four native statements, two thousand three hundred thirteen second-voice
statements, overlap zero. Only the second has an outside proof assistant
adjudicating identity and a reader that does not import the renderer. The
native side uses the same parser on both ends. Calling both surfaces one
instrument hid the construction boundary. No sentences were rendered under
the registered draw — zero of fifty in the reserve, zero of five hundred in
the run — so there is no collision table to hand to the inbound slice, and
no injectivity sentence either.

A third measurement, the leftover half of a plan this cycle had already
overruled, asked a smaller question: when the same recorded answering turns
are served today, do the bytes change? Two hundred twenty answering turns,
exact rendered-answer digests, two hostile controls that can go red. Zero
of two hundred twenty changed. That zero is a count for this window. It is
not a proof that answers cannot regress. Two live pins did move, and the
record says so.

## What this does not license

It does not license “the person finally spoke.” The person was not asked
a new question set, and the old set did not point at the speakable
remainder.

It does not license an echo of the native voice. The native voice still
has no outside adjudicator.

It does not license inventing twenty corrections to fill a denominator
that was never sealed.

## What comes next: an ordinary turn is not a keyword

The live surface already showed a smaller failure than the inbound
design assumed. On the shipped Codex-compatible harness, `hello` is
treated as an ungrounded proposition and the reply suggests holding it
as conjecture. That is technically honest and socially wrong, and it
does not need two thousand three hundred named statements to be real.

[The design written for that](../DESIGN-protocol-uptake.md) — written
and reviewed before this post, so the next question could not be chosen
after these zeros — does not make `hello` a command. It asks whether
context and corpus evidence together can take the same short utterance
as different interaction moves, and pause when they cannot, on a new
third profile that does not rewrite the two shipped surfaces. Execution
stays parked. The next course still has to weigh that against a standing
prohibition: no untrusted stream reaches the write gate until that
perimeter has been attacked.

If the ordinary turn still cannot be taken as a greeting without becoming
a keyword, that will be a finding too. The last two releases have been
honest about findings. This one is the third.
